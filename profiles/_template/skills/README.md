# Profile skills

Add only the domain skills this profile needs. The generic skills live in
`skills/` and must not be copied here.

Each skill is a directory with a `SKILL.md` and standard frontmatter. The name is the
directory name. If the skill or a review rule changes, add an eval case and a rubric in
`evals/` and record the score in `docs/EVAL-BASELINE.md`.

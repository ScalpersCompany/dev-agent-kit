These rules are appended to the DevAgentKit core GGA rules. Replace this file with the
language or stack contract for this profile: exact lint, static-analysis, test and build
commands; version and dependency rules; framework and security rules; test patterns; and
the evidence the profile requires. Do not repeat the core rules and do not weaken them.

without GGA rules must be explicit, not silently inherit another profile's rules.
